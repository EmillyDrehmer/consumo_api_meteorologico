# Sobre o projeto

Este projeto tem como objetivo consumir uma API meteorológica para obter informações sobre as condições climáticas e apresentar os dados de forma visual por meio de uma interface desenvolvida com Streamlit.

# Funcionalidades

Consumo de uma API de dados meteorológicos.

Consulta de informações climáticas.

Tratamento e organização dos dados recebidos em formato JSON.

Exibição das informações em uma interface web utilizando Streamlit.

# Tecnologias utilizadas

Python: linguagem utilizada no desenvolvimento.

Streamlit: criação da interface gráfica.

Requests: realização de requisições HTTP para a API.

API Meteorológica: fornecimento dos dados climáticos.

# COMO EXECUTAR O PROJETO

1. Clonar o repositório

git clone URL_DO_REPOSITORIO

2. Acessar a pasta do projeto

cd consumo_api_meteorologico

3. Instalar as dependências

pip install -r requirements.txt

4. Executar a aplicação

streamlit run frontend_03.py

# Após executar o comando, o Streamlit disponibilizará um endereço local para acessar a aplicação pelo navegador.
